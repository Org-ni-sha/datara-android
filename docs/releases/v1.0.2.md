DATAra 1.0.2 keeps forecasting while the app is closed. It is otherwise the same as [1.0.1](v1.0.1.md): same features, same forecast model (`final-2026-11-17`).

## What changed

- **Forecasts, alerts and usage totals in the background:** in 1.0.0 and 1.0.1, after you opened DATAra and then left it, the hourly forecast stopped until you opened the app again. The quota alerts and the 10-minute usage totals paused too. Usage was still measured, so no data was lost, but hours went without a forecast. 1.0.2 keeps all of them running while the app is closed.

Why it happened: when an app goes to the background, the sign-in library DATAra uses (Supabase) pauses the session and reports it as "loading" until the app is opened again. DATAra's background work read that as "signed out". It now uses the sign-in saved on the phone instead, as it already did when offline.

## Updating

Install 1.0.2 over 1.0.1 or 1.0.0. Your quota, usage history and settings stay.

## Good to know

- Forecasts still need the phone to be awake for the hourly reading. A phone asleep with the screen off can skip an hour; the next reading catches up the measured usage.
- Everything else in the [1.0.0 notes](v1.0.0.md#good-to-know) still applies.
