DATAra 1.0.1 installs on 32-bit Android phones. It is otherwise the same as [1.0.0](v1.0.0.md): same features, same forecast model (`final-2026-11-17`).

## What changed

- **32-bit phones:** some budget phones, such as some Samsung Galaxy A13 4G units, run a 32-bit version of Android. 1.0.0 only included 64-bit code, so Android refused it with "App not installed as app isn't compatible with your phone". 1.0.1 includes both.
- **Download size:** about 73 MB (1.0.0 was about 47 MB), because the 32-bit forecasting library is now included.

## Updating

Install 1.0.1 over 1.0.0. Your quota, usage history and settings stay.

## Good to know

- **Android 8.0 or newer**, on an ARM phone (64-bit or 32-bit).
- Everything else in the [1.0.0 notes](v1.0.0.md#good-to-know) still applies.
